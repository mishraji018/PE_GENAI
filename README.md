## Case Study: Weather Recognition

To run the Weather Recognition case study:

1.  **Download the Dataset**: The dataset is not included in this repository due to its size. You can download it from Kaggle:
    *   **Dataset Name**: Weather image Recognition
    *   **Link**: [https://www.kaggle.com/datasets/jehanbhathena/weather-dataset](https://www.kaggle.com/datasets/jehanbhathena/weather-dataset)

2.  **Setup Directory**:
    *   After downloading, extract the archive.
    *   Place the `dataset` folder inside `CASE_STUDY_WEATHER_RECOGNITION/archive/`.
    *   The structure should look like: `CASE_STUDY_WEATHER_RECOGNITION/archive/dataset/` (containing folders like `dew`, `fogsmog`, etc.).

3.  **Run the Notebook**:
    *   Open `CASE_STUDY_WEATHER_RECOGNITION/01.ipynb` and run the cells.
